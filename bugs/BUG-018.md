## Comportamiento actual
`OperacionManualService.SubirComprobanteGastoAsync` lanza una excepción de regla de negocio cuando OCR no extrae datos y la captura como error interno. No existe alternativa para completar datos manualmente ni para guardar como evidencia sin OCR.

## Comportamiento esperado
El usuario debe poder cargar otro archivo, completar datos manualmente o guardar evidencia sin OCR, sin considerarla crédito fiscal.
