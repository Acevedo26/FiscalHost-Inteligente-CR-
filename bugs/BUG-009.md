## Pasos para reproducir

1. Iniciar sesión en el frontend QA.
2. Abrir Configuración.
3. Seleccionar Log de Auditoría.

## Comportamiento actual

Al seleccionar Configuración → Log de Auditoría, la UI muestra el modal “Recurso No Encontrado” con el mensaje “No se encontró configuración.”; no presenta registros de auditoría.

## Comportamiento esperado

Abrir la bitácora y mostrar los eventos registrados con usuario, fecha y hora.

## Evidencia

Frontend local: modal visible con título y mensaje indicados. El resultado se obtuvo por la UI; no se consultó directamente la BD. No se persistió captura como archivo.

## Estado de verificación

Reproducido durante el ciclo frontend del 06/10/2026.

## Corrección aplicada (15/10/2026)

Configuración carga los recursos bajo demanda: la consulta de perfil y actividades se realiza solo en la sección Perfil, mientras que la bitácora se solicita al abrir Log de Auditoría. La ausencia de configuración tributaria deja de generar el modal global que ocultaba la bitácora.

**Verificación técnica:** el build del frontend finalizó correctamente y la API corregida inició en http://localhost:5062. Falta una sesión QA autenticada para confirmar visualmente la lista de auditoría.

**Estado:** Corregido localmente — pendiente revalidación QA autenticada.
