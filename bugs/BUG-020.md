# BUG-020 — Acceso temporal no implementa avisos a 7 y 1 día

## Identificación
| Campo | Valor |
|---|---|
| **ID del bug** | BUG-020 |
| **Título del error** | El proceso de expiraciones solo consulta accesos dentro de 3 días |
| **Caso de prueba relacionado** | CP-016-03 |
| **Fecha de reporte** | 19/10/2026 |
| **Reportado por** | Codex QA |

## Clasificación
| Campo | Valor |
|---|---|
| **Prioridad** | Alta |
| **Severidad** | Mayor |
| **Estado** | Abierto |
| **Tipo** | Funcional |

## Comportamiento actual
`ProcesarExpiracionesAsync` consulta avisos solo hasta `ahora.AddDays(3)` y genera una notificación genérica; no implementa el aviso requerido a 7 y 1 día.

## Comportamiento esperado
Notificar a 7 y 1 día antes de la expiración y negar el acceso tras vencer.
